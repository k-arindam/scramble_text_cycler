# Example

Run the example app:

```bash
cd example
flutter run
```

This demo showcases three modes:

1. **Single-line cycling** — Words transition with a scramble effect and easing curve
2. **Multi-line with stable height** — `maxLines: 3` keeps layout stable across entries with 1, 2, or 3 lines
3. **Custom character pool** — Binary `01` characters for a Matrix/terminal aesthetic
